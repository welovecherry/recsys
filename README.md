# 추천시스템 10주 실습

금융 상품(주식·ETF) 추천시스템을 10주에 걸쳐 단계적으로 만들어 보는 수업 자료입니다.
매 주차 같은 데이터·같은 채점 방식(Recall@10)을 써서 모델이 정말 나아지는지 비교합니다.

## 폴더

```
data/        합성 데이터 + 생성 스크립트
notebooks/   주차별 실습 노트북, 공용 도구(recsys.py)
app/         주차별 점수 기록
```

## 실행

```bash
uv run jupyter lab
```

데이터를 다시 만들려면:

```bash
uv run python data/make_data.py
```

## 주차

| 주차 | 내용 | Recall@10 |
|---|---|---|
| 1 | 전체 인기순 추천 (기준점) | 0.2163 |
| 2 | 규칙 기반 추천과 지표 | |
| 3 | 데이터 나누기와 누수 | |

## 데이터

`data/`의 CSV는 모두 `make_data.py`로 만든 **합성 데이터**입니다. 실제 투자자 정보가 아닙니다.

- 종목 100개 · 투자자 300명 · 거래 기록 8,086건
